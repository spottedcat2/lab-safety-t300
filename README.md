# 💀 盐城工学院实验室安全课程终结者 T300

> 面向 `sa.ycit.edu.cn` 实验室安全课程的学习辅助工具。
> 本仓库仅发布**混淆保护后的售卖版**，用于项目展示，不提供可读源码。

## ✨ 功能特性

**精美 UI**：毛玻璃高级面板、Tab 平滑动画、可拖拽悬浮球、倍速滑块

**智能答题**：课程视频习题自动作答（走授权中转服务，按题计费）

**视频自动管理**：自动展开章节、自动播放、播完自动切换、多倍速

**考试模式**：考试题目自动作答、自动翻题、末题自动提交

**复习模式**：逐课检测错题/空题，一键直答修复，无错无空自动跳过

## 🔒 使用说明

1.在 Tampermonkey 中安装本脚本（`dist/lab-safety-selling.obf.js`）
2.面板内填入卡密 → 激活 → 按需开启功能

> 脚本需要连接授权中转服务完成答题与扣费，未激活无法使用全部功能。
