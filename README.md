# LabSafety T300

面向盐城工学院实验室安全课程的视频学习与复习辅助工具。

适用网站：**sa.ycit.edu.cn**（盐城工学院实验室安全课程）

本仓库仅发布经过混淆保护的可安装版本，不提供可读源码。

## 主要功能

- **视频学习管理**：调整播放倍速，集中查看视频学习状态。
- **章节自然衔接**：自动展开章节，并在视频结束后衔接后续内容。
- **随堂互动辅助**：识别视频学习过程中的随堂互动，减少重复操作和流程中断。
- **重点复习**：按章节回顾错题与空题，把复习范围集中到薄弱内容。
- **便捷控制面板**：可拖动、可收起，并提供清晰的分区设置。

## 下载与安装

1. 从 [GitHub Releases](https://github.com/spottedcat2/lab-safety-t300/releases/latest) 下载 `lab-safety-selling.obf.js`。
2. 在电脑浏览器中安装 Tampermonkey（篡改猴）。
3. 首次启用时，进入浏览器扩展设置，将"允许插件在网址加载脚本"设为"允许"。
4. 打开 Tampermonkey 管理面板，选择"实用工具 → 从文件导入"，导入下载的脚本。
5. 登录 `sa.ycit.edu.cn`。页面右下角出现 T300 面板，即表示安装成功。

脚本本体可免费下载。部分智能辅助能力需要调用在线模型并持续运行服务，相关授权费用用于覆盖模型调用、服务器、适配开发和持续维护成本。

## v2.5.1

- 更新了服务器，优化请求链路与响应延迟。
- 视频题改为切换课程后直接从课程接口后台取题和提交，不再等待题目弹窗出现；弹窗只会短暂闪现，不再阻塞播放流程。
- 复习模式先判断课程是否已经完成。满足条件的课程直接跳过，不调用 AI；需要修正的课程才进入后台答题，已学完且仅剩题目要求时，答完后直接切换下一课程。
- 考试开始时一次获取整张试卷，将 100 道题按每批 10 道拆分，最多同时处理 3 批，取代原来逐题等待、逐题请求和逐题翻页的串行流程。
- 并发批次按题目 ID 合并，即使返回顺序不同也不会写错答案；成功响应只重试缺失题目，网络超时不盲目重试，避免重复调用和重复扣费。
- AI 请求超时由 15 秒调整为 70 秒，与服务器 60 秒上游超时对齐，避免客户端提前结束而服务器仍在执行。
- 考试答案达到完整数量后一次写入网页答案状态，多选题保持字母数组格式；未达到完整数量时停止自动提交。
- 状态显示改为按批次事件更新，不使用高频刷新，不增加可感知的页面延迟。
